# 🎙️ Транскрибер

Приложение для Mac: аудио и видео → текст. **Полностью на твоём компьютере** — без интернета,
без подписок и без оплаты за минуты. Записи никуда не уходят.

Движок — **Whisper large-v3-turbo** на [whisper.cpp](https://github.com/ggml-org/whisper.cpp)
с ускорением Metal. Час записи расшифровывается за несколько минут.

## Кому пригодится

- **Учишься по курсам** — кидаешь папку с курсом на 40 часов и получаешь текст каждого урока
  одним файлом с оглавлением. Дальше поиск по курсу за секунды и саммари через ИИ.
- **Психологам и коучам** — расшифровка сессий, которая не покидает твой Mac.
- **Врачам** — запись приёма → текст для дневника.
- **Авторам курсов и поддержке** — расшифровка курса как база знаний для ИИ-куратора.
- **Планёрки, созвоны, интервью, голосовые** — всё, что проще сказать, чем напечатать.

## Установка

Нужен Mac на Apple Silicon (M1 и новее), macOS 12+, ~2 ГБ места.

1. Скачай `Транскрибер-1.2.0-arm64.dmg` со страницы
   [**Releases**](https://github.com/almirmusali/audio-transcriber/releases/latest).
2. Открой, перетащи «Транскрибер» в «Программы».
3. Приложение не подписано в Apple, поэтому при первом запуске macOS его заблокирует.
   Открой «Терминал» и вставь одну строку:
   ```sh
   xattr -cr "/Applications/Транскрибер.app"
   ```
   Или: правый клик по иконке → «Открыть» → «Открыть».

## Возможности

- Распознавание на ~100 языках: русский, English, Bahasa Indonesia и другие
- Файл, перетаскивание или запись с микрофона (пауза, таймер, плашка поверх окон)
- **Папка целиком** — весь курс превращается в один `.md` с оглавлением
- Текст появляется по мере распознавания, с тайм-кодами
- Экспорт в **TXT** и **SRT** (субтитры)
- **Словарь имён** — впиши имена и термины, которые распознавание путает
- Обработка текста через Claude своим промптом — саммари, чистовик, пост
  (нужен ключ Anthropic или установленный [Claude Code](https://claude.com/claude-code); без них всё остальное работает)
- Веб-версия для телефона — запись с айфона, распознавание на твоём Mac ([server/](server/README.md))

## Сборка из исходников

Нужно: Node.js, cmake (`brew install cmake`), Xcode Command Line Tools.

```sh
npm install
npm run setup        # модель (~550 МБ), ffmpeg и whisper-cli со статической линковкой
npm run app          # режим разработки
bash scripts/make-installer.sh   # установщик .dmg в release/
```

## Как устроено

- **Интерфейс** — React + Vite + TypeScript (`src/`).
- **Electron** (`electron/main.cjs`) — ffmpeg переводит вход в WAV 16 кГц, `whisper-cli`
  распознаёт и стримит сегменты в интерфейс, результат пишется в TXT/SRT.
- **Модель и бинарники** (`resources/`) в git не хранятся — их ставит `npm run setup`.
