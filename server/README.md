# Транскрибер на телефоне

Веб-версия «Транскрибера»: айфон только пишет звук и показывает текст,
всё распознавание идёт на твоём Mac (whisper.cpp `large-v3-turbo` + Metal).
Доступ только внутри своей сети Tailscale — в интернет ничего не торчит.

**Адрес:** `https://<имя-мака>.<твой-тайлнет>.ts.net:8443`

## Как пользоваться с айфона

1. На телефоне включён **Tailscale** (тот же аккаунт).
2. Открыть адрес в **Safari** → «Поделиться» → **«На экран “Домой”»**.
   Иконка появится как у обычного приложения, откроется без адресной строки.
3. Красная кнопка — запись с микрофона (первый раз Safari спросит доступ).
   «Выбрать файл» — любой аудио/видео из «Файлов», «Фото» или голосовая заметка.
4. Текст течёт на экран по мере распознавания. Готовый — «Копировать»,
   «Поделиться», TXT, SRT. Кнопки ✨/📋/✍️ прогоняют текст через локальный
   `claude` (по подписке, без API-ключа).

Телефон можно заблокировать или свернуть — работа идёт на сервере, при
возврате страница сама подхватит задание (id лежит в localStorage).
Записи, TXT и SRT остаются в `~/Documents/Транскрибер/Телефон/<id>/`,
последние 50 показаны в «Истории».

## Почему HTTPS

iOS даёт микрофон только в secure context. TLS терминирует Tailscale:

```sh
tailscale serve --bg --https=8443 http://127.0.0.1:8773
```

Сертификат — валидный для MagicDNS-имени, поэтому работает именно
полное имя `<имя-мака>.<тайлнет>.ts.net:8443`, а не короткое имя и не IP.

## Сервис

- Node без зависимостей, слушает **127.0.0.1:8773** (наружу — только через Tailscale).
- Автозапуск: шаблон LaunchAgent `transcriber-web.plist.example`, лог `~/Library/Logs/transcriber-web.log`.
- Перезапуск: `launchctl kickstart -k gui/$(id -u)/transcriber-web`
- Вручную: `npm run web` (переменные `PORT`, `HOST`, `TRANSCRIBER_DATA`).
- Бинарники и модель берутся из `resources/`, а если их нет — из
  `/Applications/Транскрибер.app/Contents/Resources`.
- Задания идут по одному в очереди: Metal всё равно один.

## API

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/jobs?name=&lang=&fast=&mic=` | тело — сырые байты аудио, ответ `{id}` |
| GET | `/api/jobs/:id/events` | SSE: `state`, `progress`, `partial`, `done` |
| GET | `/api/jobs/:id` | состояние задания |
| POST | `/api/jobs/:id/cancel` | остановить |
| GET | `/api/jobs/:id/txt` · `/srt` · `/audio` | скачать |
| POST | `/api/jobs/:id/ai` | `{preset:"clean"\|"summary"\|"post"}` → текст |
| GET | `/api/history` | последние задания |

Отсюда же удобно дёргать транскрибацию из «Быстрых команд» iOS:
`Получить содержимое URL` → POST на `/api/jobs`, тело — файл.
