# Транскрибер для айфона

Нативное приложение к веб-серверу Транскрибера (`server/`): телефон пишет звук,
распознаёт и размечает говорящих твой Mac, совещание одной кнопкой (или сразу после
записи) уходит в Орбиту за саммари.

- **Запись при погасшем экране.** Фоновый режим `audio`; звонок ставит запись на паузу,
  после него она продолжается в тот же файл.
- **Запись не теряется.** Звук пишется в AAC с заголовками ADTS (`.aac`): у каждого кадра
  свой заголовок, поэтому файл читается до последнего кадра, даже если систему убьёт
  приложение посреди совещания. m4a и CAF/AAC пишут оглавление только при закрытии —
  оборванный файл у них нечитаем. Оборванная запись при следующем запуске уходит на
  распознавание сама, с пометкой «(прервана)».
- **Фоновая загрузка.** После «Стоп» телефон можно убрать: файл дольётся через
  фоновую URLSession. Копия на телефоне удаляется, когда сервер закончил распознавание.
- **Файлы со стороны.** «Выбрать файл» или «Поделиться → Транскрибер» из Диктофона,
  Файлов, Телеграма. Свои записи видны в «Файлах» → «На iPhone» → «Транскрибер».

## Сборка

Нужны Xcode, `xcodegen` и два файла с настройками (в репозитории их нет):

```sh
echo "https://<мак>.<тайлнет>.ts.net:8443" > ~/.config/transcriber/ios-server-url
echo "<Team ID>" > ~/.config/transcriber/ios-team
make install
```

С бесплатным Apple ID подпись живёт 7 дней — раз в неделю `make install`.
Проверка компиляции без подписи — `make sim`.
