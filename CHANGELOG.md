# История версий

## 1.1.0 — 10 сентября 2026

- **Имя файла по смыслу.** Кнопка «⬇ TXT» больше не предлагает `transcript.txt`:
  Sonnet читает начало расшифровки (первые 100 символов) и придумывает название —
  «Разбор падения конверсии», «Планёрка по найму». Не ответил — остаётся `transcript.txt`.
  Сначала пробуем локальный `claude` CLI (бесплатно, по подписке), потом ключ из панели ИИ.
- **Кнопка «💡 Идея».** Отправляет расшифровку в «Банк идей» на :8771 — он сам
  разбирает её на идеи, а из приложения открывается ссылка на банк.

## 1.0.0 «Публичная» — 10 сентября 2026

Первая публичная версия: приложение собрано в установщик `.dmg` и выложено в репозиторий.

- Распознавание аудио/видео локально: whisper large-v3-turbo + Metal, ~100 языков
- Живой вывод текста по мере распознавания, тайм-коды, экспорт TXT и SRT
- Запись с микрофона: пауза, таймер, плавающая плашка поверх окон
- Папочный режим: целый курс из папки → один `.md` с оглавлением
- AI-обработка транскрипта по своему промпту
- Личный словарь имён и терминов для whisper (`~/.config/whisper/dictionary.txt`)
- Интерфейс на русском и Bahasa Indonesia
- Веб-версия для телефона (`server/`) — та же модель, доступ через Tailscale

Сборка установщика: `bash scripts/make-installer.sh` → `release/Транскрибер-1.0.0-arm64.dmg`.
